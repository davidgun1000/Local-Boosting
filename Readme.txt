This MATLAB software implements the mixture of Gaussians variational approximation with global and local boosting steps.

The paper has two examples.
The first example is the random effects logistic regression model with three non-standard priors. We refer to the first prior as bimodal prior, the second prior as the variable selection prior, and the last prior as the heavy-tailed prior based on the Z-distribution. 

The second example is the time-varying parameter regression models; see Section 6 of the main paper for further details. 
There are two folders. 
The "first example" folder contains the matlab code for the random effects logistic regression models.
The "second example" folder contains the matlab code for the time-varying parameter regression models.

This folder contains code to replicate figures in Section 6.1 and Section S7 of the online supplement.The main code is plotting.mHMC_mixT_full1_Bimodal.m contains the HMC posterior draws for bimodal priors. HMC_mixT_full1_VS.m contains the HMC posterior draws for variable selection priors. HMC_Z_full.m contains the HMC posterior draws for Z priors. The figures in the main paper are created with the full 50000 draws. However, the files are too big to be included in the submission, and we provide the thinned version of posterior draws.
